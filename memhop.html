引擎详解

MemHop 认知记忆引擎

像人脑一样组织记忆 — 身份、情景回忆、语义压缩、技能习得、归档存储、结晶专长

Go 1.26+ MIT OR Apache-2.0 4 Direct Deps

一句话定位

MemHop 不是向量数据库，而是模仿人脑组织知识的记忆系统 — 有身份、情景回忆、语义压缩、技能习得、归档存储和结晶专长。一个 Agent，一个 .meh 文件，零基础设施。

纯 Go，4 个直接依赖，无 cgo，无外部服务（除 embedding/LLM 端点）

为什么需要认知记忆？

❌ 传统向量数据库

bolt-on 向量插件或 plain-text log 塞进 context window。Agent 没有内化记忆 = 无状态函数伪装智能。

VS

✅ MemHop 认知记忆

记忆必须是认知的 — 结构化、压缩、整合、遗忘，像人脑一样；且嵌入式的 — 存活在 Agent 进程内，而非网络调用之后。

核心设计思想

记忆不是事后补丁，而是 Agent 智能的基础

🧠

认知 > 向量

六层认知架构，从身份到结晶技能，模拟人脑的记忆层级。不是扁平向量库的相似度匹配。

🔌

嵌入式 > 服务化

一个 .meh 文件，零基础设施。MemHop 作为嵌入式器官运行在 Agent 进程内，无需启动服务器。

💤

整合 > 堆叠

Dream 休眠整合：压缩、重建、衰减、画像。睡眠后记忆更清晰，而非不断堆叠 token。

🗑️

遗忘 > 全记

基于重要性的衰减，而非基于时间。弱连接修剪，强关联保留。像人脑一样遗忘无关细节。

六层认知架构

从身份到结晶技能，每层有明确的人脑对应机制

L0

L0 Profile 身份

Agent 人格、偏好与语言习惯

L1

L1 Engram 关联超图

链接 L2 上下文的超图骨架

L2

L2 Context 工作记忆

压缩的主题结构（4 级深度）

L3

L3 Knowledge 语义记忆

多源超图知识库 + 社区检测

L4

L4 Archive 长期记忆

原始对话日志与历史记录

L5

L5 Crystal 肌肉记忆

结晶化程序与可复用技能

三通道 RRF · Dream · .meh 存储 · 单实例

🔀 三通道 RRF 检索

BM25 (gse CJK) + f16 向量 (Ollama) + 实体模糊匹配，RRF(k=60) 融合

💤 Dream 整合管道

五阶段 L0-L2 整合：压缩→重建→衰减→画像→蒸馏，每次最多 3 次 LLM 调用

💾 V2 .meh 存储

A/B 双头 + CRC32 + 断电恢复 + mmap 零拷贝 + 快照/检查点

🔒 单实例设计

一个 Agent = 一个 .meh 文件，跨平台文件锁（Linux/macOS/Windows）

Dream 整合管道

受人脑睡眠处理经验启发，自动记忆整合流程。仅作用于 L0-L2（L3 蒸馏与 L5 结晶不在范围内）

01

L2 压缩

LLM 分组并合并相关主题，降级过时上下文

02

L1 重建

重建链接 L2 上下文的超图骨架

03

L1 衰减

衰减情景重要性，修剪弱节点/边

04

L0 画像

从整合后的记忆重新生成 Agent 画像

05

L0 蒸馏

蒸馏情绪/MBTI 模式（可选，SkipDistill）

快速开始

前置条件: Go 1.26+, Ollama (ollama pull qllama/bge-m3:q4_k_m), OpenAI 兼容 LLM 端点

01

打开数据库

Go
import (
    "context"
    "time"

    memhop "github.com/qyiun666/MemHop/api"
)

db, err := memhop.Open(&memhop.Config{
    DBPath:      "agent.meh",
    VectorDim:   768,
    EncoderAddr: "http://127.0.0.1:11434",
    EmbedModel:  "qllama/bge-m3:q4_k_m",
    LLM: memhop.LlmConfig{
        APIURL: "https://api.openai.com/v1",
        APIKey: os.Getenv("OPENAI_API_KEY"),
        Model:  "gpt-4o-mini",
    },
})
if err != nil {
    log.Fatal(err)
}
defer db.Close()
02

搜索记忆

Go
// Timestamp 为必填：消息的 Unix 毫秒时间戳
results, _ := db.Search(memhop.SearchQuery{
    Text:       "What did we discuss?",
    Timestamp:  time.Now().UnixMilli(),
    MaxResults: 10,
})

// 将 Agent 回复追加到 Search 创建的 topic
_ = db.Update(results.NewTopicID, "Agent: ...", time.Now().UnixMilli())
03

Dream 整合

Go
// Dream 整合（L0-L2），每次最多 3 次 LLM 调用
// 并发调用会被串行化（第二次返回 error），支持 ctx 取消
report, _ := db.Dream(context.Background(), nil)
log.Println(report)
