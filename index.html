✨ 核心特性

量子架构 + 双脑路由 + 分层记忆

🪐

量子记忆

  • 纠缠图 — 记忆间自动关联，形成知识网络
  • 观测坍缩 — 每轮独立观测，坍缩出 Top-K 相关记忆
  • 退相干遗忘 — coherence 低于阈值自动归档
恒定制：每轮 context 永远不超过固定 Token
🤖

双脑路由

  • A 模型（小脑） — 本地快速路由判断，处理简单任务
  • B 模型（大脑） — 大模型深度推理，解决复杂问题
  • 启发式学习 — B 的决策沉淀为 A 的规则，越用越聪明
A 直接处理 + Skill/MCP = 极少调用 B
📦

六层记忆

  • L1-L2 共享 — 用户信息、画像跨会话共享
  • L3-L6 会话独立 — 身份、知识、归档、原始日志
  • 知识库模式 — L4/L5/L6 按目录隔离
分层存储确保信息不丢失也不过载
⚡

技能自生长

  • 内置 Skill — 文件操作、天气查询、网络搜索
  • 自生长 — 重复模式 ≥3 次自动生成 Skill 模板
  • MCP 支持 — 自动发现和使用外部工具
你的习惯自动结晶为可复用能力

⚡ 快速开始

三步完成安装与配置

1

安装

macOS / Linux
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Axonant/MeowAgent/main/scripts/install.sh)"
然后
source ~/.bashrc   # or ~/.zshrc
2

配置模型

交互式配置
meowagent --config

添加本地模型 (A) 和 API 模型 (B)

3

开始对话

启动
meowagent

💻 命令参考

30+ 子命令，覆盖对话、模型、记忆、技能、浏览器等

💬 对话

  • meowagent 启动交互式聊天
  • meowagent chat --new 创建新会话
  • meowagent chat --list 列出会话
  • meowagent chat --switch 切换会话

🤖 模型

  • meowagent model 交互式配置
  • meowagent model add --for a 添加 A 模型
  • meowagent model add --for b 添加 B 模型
  • meowagent model test 测试连接

🧠 记忆

  • meowagent memory list 列出记忆
  • meowagent memory export 导出
  • meowagent memory rebuild 重建 L3
  • meowagent knowledge 知识库模式

⚡ 技能 & MCP

  • meowagent skill list 列出技能
  • meowagent mcp list 列出 MCP 工具

🌐 多平台

  • meowagent platform add 添加平台
  • meowagent serve 启动服务器
  • meowagent browser open 打开网页

🔧 系统

  • meowagent update 更新版本
  • meowagent doctor 环境检查
  • meowagent language set zh 切换中文
  • meowagent stats 对话统计
